# Security Policy

Portman inspects and kills processes — report anything exploitable (a hidden exposure, privilege escalation, a crash on untrusted input) privately, not as a public issue.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/zalaya/Portman/security/advisories/new). If that's unavailable, open an issue asking for a private contact instead.

Please include:

- What you found and why it matters.
- Steps to reproduce, or a proof of concept if applicable.
- The platform/OS you tested on.

## Supported versions

Portman is pre-1.0 — only the latest release is supported. Fixes land on `main` and go out in the next tagged release.
